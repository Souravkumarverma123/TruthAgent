# Plain full-stack Next.js app, not the tRPC monorepo starter

We considered starting from `piyushgarg-dev/trpc-monorepo` (Turborepo, Express + tRPC API, Postgres/Drizzle in Docker, Google OAuth, Next.js 16 + shadcn). We chose a single `create-next-app` project (UI in `app/`, pipeline in `lib/engine/`, API routes in the same app, one Vercel deploy) because most of what the template adds is what we deliberately cut: a separate backend, a database server, Docker and login. Our API is two endpoints (a streaming "check" and "get result"), so tRPC buys little, and nobody on the 5-person team has used the template before, while all of us have built full-stack Next.js apps. The template's useful parts (shadcn components, Tailwind 4, env validation, prettier config) are reproducible in minutes.
