# TruthAgent

Paste a forward (text and/or image), get a plain verdict with proof: evidence, citations,
confidence and reasoning. Binary Hacks 4.0, PS-05.

```bash
cp .env.example .env.local   # fill in keys
npm install
npm run dev
```
